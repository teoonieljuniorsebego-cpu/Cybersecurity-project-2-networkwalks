# W2-PM-FINAL | Footprinting & Network Scanning

Penetration testing report completed as part of the **Networkwalks Cybersecurity & Ethical Hacking Internship** (Batch B084).

This project covers:

- **Phase 1 – Reconnaissance & Footprinting**  
  Six Kali Linux tools used against the authorized target (`networkwalks.com`):
  - WHOIS
  - WhatWeb
  - Nslookup
  - Curl
  - Wafw00f
  - DNSRecon

- **Phase 2 – Network Scanning**  
  Local network discovery and topology mapping using **Zenmap** (Nmap GUI), including live host detection, IP/MAC identification, and topology export.

The full report documents methodology, findings, risk analysis, recommendations, and includes all supporting evidence screenshots.
